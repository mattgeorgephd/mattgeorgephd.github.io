# mattgeorgephd.github.io

Personal website and open lab notebook of Matthew N. George, built with Jekyll (Beautiful Jekyll
theme, vendored) and published by GitHub Pages from `master`.

- Site structure and data files: see `README.md`.
- Adding a lab notebook entry or project: follow `.claude/skills/notebook-entry/SKILL.md`.
- All changes go through a pull request for the author's review; never push to `master` directly.
- Before opening a PR, build with the GitHub Pages toolchain and run the internal link check
  (commands in `README.md`). CI runs the same checks plus an external-link report.
- Do not publish: the 2026 CV's relocation statement, home address, phone number, or references;
  application documents (teaching, research, or diversity statements) as files; credentials or
  private network addresses.
- Featured repositories on the Code & Data page are limited to those in `_data/repos.yml`; ask before
  adding others.
